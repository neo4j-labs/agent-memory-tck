# Keep the Java memory surface domain-oriented

> Refined by [ADR 0022](0022-organize-packages-around-memory-operations.md):
> MemoryClient now defines all domain operations, including raw-ID operations,
> and live handles bind to that interface across the capability packages.
> The final-handle model and private wire records remain.

The public Java surface consists of deep, vertical modules rather than a flat mirror of NAMS endpoints: the `MemoryClient` interface owns cross-conversation capabilities such as creating, listing, and retrieving conversations and searching entities, while each final live `Conversation` owns its details and conversation-scoped message, context, and reasoning-trace behavior. A conversation creates final live `ReasoningStep` objects, and each step owns its tool-call recording and explanation retrieval; immutable traces, explanations, and tool-call results remain snapshots. A trace reuses those live `ReasoningStep` objects rather than introducing a second public step DTO. Reasoning steps and traces expose their conversation UUID rather than retaining a public `Conversation` back-reference, keeping the object graph non-circular. This placement makes conversation and step identities structural instead of requiring callers to pass their UUIDs repeatedly. The root client exposes no raw step-ID fallbacks for recording tool calls or retrieving explanations; adapters translating ID-shaped tool protocols retain the returned live step handles. Live domain objects retain their remote identity and client binding but do not cache messages, context, or reasoning state; each operation uses authoritative NAMS state. `Conversation` and `ReasoningStep` are implementations rather than interfaces with second internal implementing classes. Endpoint-shaped handwritten or generated code and the HTTP transport remain internal, preserving a stable domain surface as the hosted contract evolves.

The initial route mappings and wire records are handwritten and package-private: OpenAPI generation is deferred because its POJO output and generator configuration have not been accepted. Keeping this choice internal allows later generation without changing the public domain API.
